# LCD Proxy 1.1.0 发布验收

## 这一版改了什么

- **TUN 修复**:修复前经 TUN 访问海外网站全部失败。原因是 Windows DNS 客户端同时问所有网卡,拿到物理网卡上被污染的结果;加上有 AAAA 记录的网站优先走 IPv6,而节点没有 IPv6 出口。现在开启 `strict_route`,只解析 IPv4。
- **首次访问慢 5 秒**:直连 DNS 不再用 `type: local`。TUN 下它绕回内核,Windows 虚拟网卡上失效的 `fec0::` 地址还要等超时。
- **内核进程**:放进 Job Object,主程序被杀时一起退出。
- **订阅**:支持 Clash / mihomo 配置,策略组和规则直接生效;可以同时保留多份订阅,按订阅声明的间隔自动更新。
- **存储**:拆成 `settings.json`、`profiles.json`、`profiles/`,原子写入并保留备份。旧版 `state.json` 自动迁移,原文件留为 `state.v1.json`。
- **界面**:重做成左侧导航的工具台,六个页面。

2026-11-06 在 Windows 10/11 x64 上用真实客户端验证,构建自发布代码。

| 项目 | 结果 |
| --- | --- |

| 系统代理 | 连接后代理快照正确,断开恢复 |
| TUN 连接 | 切换后提权重启并连接,约 350 ms |

| 协议栈切换 | 连接中反复切换 6 次,每次约 0.5 秒连回 |

### TUN 协议栈吞吐

单机单线程下载,同一国内镜像,仅供比较:

| 方式 | 直连吞吐 |
| --- | --- |
| 不开 TUN | 约 85 MB/s |
| 系统栈 | 约 59 MB/s |
| gVisor | 约 35 MB/s |

经节点时三者都在 10 MB/s 上下,瓶颈在节点带宽。默认保持 gVisor:不依赖防火墙放行,兼容性最好。需要更高吞吐可以在设置里换系统栈。
